# 등록

> 🔴 2026-10-27 — 클로드 코드를 열었어도 **야간비행에 등록하라고 말하지 않은 대화는 프로젝트로 등록하지 않는다** ·
> 야간비행에 등록하라고 하면 프로젝트에 등록하고 정해진 작업을 바로 시작한다」

## 무엇을 하나

야간비행 플러그인 폴더의 `bin/ledger.sh 등록` 을 부른다(플러그인 폴더: `$CLAUDE_PLUGIN_ROOT` · `$PLUGIN_ROOT` · `$CURSOR_PLUGIN_ROOT` 중 있는 것).

```bash
"${CLAUDE_PLUGIN_ROOT}/bin/ledger.sh" 등록
```

- 이 폴더에 기록 자리를 만들고 «등록» 줄을 적는다. 이미 등록돼 있으면 그렇다고만 말한다.
- 플랜의 제품등록을 다 썼거나 이 컴퓨터의 무료 제품이 이미 다른 제품이면, 그 안내와 플랜 안내 주소가 나온다 — **그대로 전한다.**
  제품등록은 설계 단계부터다(무료 제품 1개 + 플랜의 유료 — 라이트 2 · 플러스 14). 아이디어 · 검증 단계는 제품등록을 다 써도 그대로 쓸 수 있다.
- 지금 열린 곳이 제품 폴더가 아니면(홈 · 바탕화면 · 문서 · 다운로드 등) 등록하지 않고 «새 폴더 만들기» 순서가 나온다 — **그 순서를 그대로 따른다**(이름 묻기 → 폴더 만들기 → 그 폴더 등록 → 대화 옮기기).
- 출력 끝의 «정해진 작업» 순서를 **바로** 따른다: 진단 → (이미 만들던 제품이면) 가져오기 → (새 제품이면) 기획 제안 → 턴 끝의 조종석 만들기.

## ⛔ 못

1. 사용자가 등록하라고 하지 않았는데 등록하지 않는다 — 기록 명령을 먼저 쓰지도 않는다(등록 전에는 기록 명령이 «등록 안 됨»으로 멈춘다).
2. 제품등록을 다 썼다고 등록을 미루거나 막지 않는다 — 알리고 등록한다.
3. 플랜 바꾸기 · 제품등록 풀기는 사용자가 고른 뒤에만 한다.
