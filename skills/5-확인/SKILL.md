# 5-확인

> ⭐ **이 파일에는 «무엇을 하는 단계인가»만 있다.**
> 증상 표·실제 절차·판정 기준·사고 이력은 **두뇌가 내려준다**(기획 §43-6).
> ⛔ 그것을 여기 적지 않는다 — **본체는 서버에서 내려온다.**
> `tools/lint_skill_leak.py` 가 그것을 막는다.

## 무엇을 하는 단계인가

**결정 ④** 화면 확인.

## 두뇌에 무엇을 묻나

무엇을 전화기로 봐야 하는지의 목록은 **두뇌가 내려준다**.

⭐ **부르는 법** — 이 단계에 들어오면 **먼저 묻는다**:

```bash
"${CLAUDE_PLUGIN_ROOT}/bin/두뇌.sh" 5 <갈래>
```

갈래를 모르면 아무 말이나 넣으면 **물을 수 있는 갈래 목록**이 돌아온다.
⛔ 받은 것을 **파일로 적어 두지 않는다** — 적는 순간 노하우가 깔려 나간다(기획 §43-6).
⛔ 못 받아도 **멈추지 않는다.** 아는 것만으로 진행하고 **「두뇌에서 못 받았다」고 적는다.**

## ⛔ 못 — 이 단계에서 하지 않는 것

1. **스크린샷은 지시받았을 때만** 찍는다 — 한 장에 1~2분이고 그동안 기다리신다
2. **안 찍고 되는 검증은 다 하고**, 눈으로 못 본 것은 **「눈으로 확인 안 함」**이라고 적는다
3. **시뮬레이터는 두 번 실패하면 멈춘다** — 무엇을 하려 했고 어떤 오류였는지 보고한다
4. `tools/shot.sh` 를 쓴다 — 직접 조합하지 않는다
