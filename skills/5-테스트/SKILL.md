# 5-테스트


## 무엇을 하는 단계인가

**결정 ④** 화면 확인.

⭐ **AI가 할 수 있는 테스트는 AI가 먼저 한다.** «확인»이라고 부르지 않는다 — 확인은 만든 AI와 따로 띄운 에이전트가 점검한 것만이다. 테스트 칸은 두 묶음으로 깔린다.
- «AI가 하는 테스트»: 처음 켜서 끝까지 한 바퀴 · 자동 시험 통과 · 작동 안 하는 버튼과 못 가는 화면 없음 · 실패 상황에서 보이는 화면 · 다른 화면 크기 · 화면 안내와 실제 동작이 맞나 · 나쁜 상황에서 멈추거나 기록을 잃지 않나 · 위험 큰 기능부터 상태 조합 시험 · AI 답이 세 번 모두 일정한가(AI 기능이 있는 제품만) · 따로 띄운 AI의 독립 점검
- «직접 하실 테스트»: 진짜 휴대폰 · 실제 계정 로그인과 실거래 결제 · 써 보고 어색한 곳 — 조종석 «직접 테스트할 일»에 바로 보인다
⛔ AI 몫을 사용자에게 넘기지 않는다. 해 보고 막혔을 때만 `ledger.sh 세부상태 <기능> <세부> "확인 필요" "직접 — <막힌 까닭>"` 으로 넘긴다.
⭐ 단계를 끝내는 조건은 «AI가 지금 할 수 있는 일이 남지 않은 때»다 — 직접 하실 테스트 · 바깥 답 기다림(`ledger.sh 세부언제`)은 붙잡지 않고 다음 단계로 따라간다.

## AI 테스트는 보이게 한다

뒤에서 몰래 하지 않는다. 사용자가 «무엇을 왜 하고, 지금 어디쯤인지»를 조종석과 대화에서 본다.

1. 시작할 때 AI 테스트 목록을 한 번 보여 드린다 — 칸마다 «무엇을 · 왜» 한 줄. 왜는 이렇게 말한다:
   - 처음 켜서 끝까지 한 바퀴 — 사용자가 실제로 가는 길이 끝까지 이어지는지 본다(기능 하나씩은 되는데 사이가 끊기는 것을 잡는다)
   - 화면 안내와 실제 동작이 맞나 — 화면 글 · 설명 · 판매 페이지가 약속한 것이 실제로 되는지 맞춰 본다
   - 작동 안 하는 버튼과 못 가는 화면 없음 — 눌러도 아무 일이 없거나 영영 못 넘어가는 자리를 찾는다
   - 나쁜 상황에서 멈추거나 기록을 잃지 않나 — 설계에서 «처리»로 적은 실패 상황(`ledger.sh 실패점검목록`)을 하나씩 실제로 일으켜, 적은 대로 보이는지 본다
   - 위험 큰 기능부터 상태 조합 시험 — 돈 · 법 · 되돌릴 수 없는 일에 묶인 기능부터, 설계의 상태 그림(`ledger.sh 상태목록`)에서 갈 수 있는 길마다 한 번씩 지나가 본다(기능 하나씩은 되는데 어떤 순서로 가면 막히는 것을 잡는다)
   - AI 답이 세 번 모두 일정한가 — 앱의 AI 기능에 같은 질문을 세 번 넣어 답의 꼴과 뜻이 같은지 본다(한 번 맞은 것은 우연일 수 있다)
   - 따로 띄운 AI의 독립 점검 — 만든 AI가 아닌 AI가 처음 보는 사람처럼 써 보고 고장을 찾는다
2. 칸 하나를 시작할 때 `ledger.sh 하는중 "<칸 이름> (<몇째>/<전체>)" --화면 "<칸 이름> 테스트하는 중 (<몇째>/<전체>)"` 을 적는다. 조종석 «지금 작업»에 바로 보인다.
3. 찾은 것은 그때마다 `ledger.sh 찾음 "<한 줄>"` 로 적는다 — 고장이면 고치고 그 칸을 다시 돌린다.
4. 칸을 끝내면 `ledger.sh 세부상태 "AI가 하는 테스트" "<칸 이름>" 완료 "<무엇을 돌려 무엇을 봤나>"` 와 `ledger.sh 하는중끝` 을 적고, 대화에 한 줄로 «끝났습니다 — 찾은 것 몇 가지» 을 말한다.
5. «따로 띄운 AI의 독립 점검»은 맨 마지막이다. Agent 도구로 따로 둘을 띄운다 — ① 처음부터 끝까지 써 보기 ② 며칠 쓰는 중의 나쁜 상황. 만든 AI의 «다 됐다»는 판단은 넘기지 않는다. 둘 다 «높음»이 하나도 없으면 완료다. 에이전트를 띄울 수 없는 도구면 «독립 점검을 못 했습니다»라고 말하고 «확인 필요»로 둔다.
6. AI 테스트를 다 끝내면 «직접 하실 테스트»를 할 일로 드린다 — 칸마다 무엇을 · 어떻게 · 몇 분쯤. 직접 하실 테스트는 다음 단계로 넘어가도 남은 일로 따라간다.

## 두뇌에 무엇을 묻나

무엇을 전화기로 봐야 하는지의 목록은 **두뇌가 내려준다**.

⭐ **부르는 법** — 이 단계에 들어오면 **먼저 묻는다**:

```bash
"${CLAUDE_PLUGIN_ROOT}/bin/brain.sh" 5 <갈래>
```

갈래를 모르면 아무 말이나 넣으면 **물을 수 있는 갈래 목록**이 돌아온다.
⛔ 받은 안내를 **파일로 적어 두지 않는다** — 안내는 늘 서버의 최신 판을 받아 쓴다.
⛔ 못 받아도 **멈추지 않는다.** 아는 것만으로 진행하고 **「두뇌에서 못 받았다」고 적는다.**
