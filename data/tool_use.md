# 클로드 코드 기능을 쓰는 법

클로드 코드에서 이 도구가 있을 때만 씁니다. 없으면 건너뛰고 하던 방법으로 진행합니다.
사용자에게 기능 이름을 설명하지 않습니다. 사용자가 겪는 결과만 말합니다.

## 계획 먼저 보여 주기

- 쓰는 때: 설계표에 없던 큰 변경, 데이터 구조 변경, 여러 기능에 걸친 수정.
- 하는 법: `EnterPlanMode` 로 계획을 세워 보여 주고, 승인을 받은 뒤 고칩니다.
- 쓰지 않는 때: 설계표에 있는 세부기능을 차례대로 만들 때. 개발 단계에서는 말을 걸지 않습니다.

## 진행 표시

- 쓰는 때: 단계가 셋 이상이거나 오래 걸리는 작업.
- 하는 법: 할 일 도구로 단계를 적고, 하나를 끝낼 때마다 바로 표시합니다.
- 까닭: 사용자가 도는 중인지 멈췄는지 구별할 수 있습니다.

## 화면 직접 확인

- 쓰는 때: 웹 화면을 만들거나 고친 뒤. 데스크톱 앱의 브라우저 도구가 있을 때만입니다.
- 하는 법:
  1. `.claude/launch.json` 에 개발 서버를 적습니다. 비밀값은 적지 않습니다.
  2. `preview_start` 로 서버를 띄웁니다.
  3. `read_page` 와 `read_console_messages` 로 내용과 오류를 봅니다.
  4. 버튼을 눌러 봅니다. 문제가 있으면 고치고 다시 봅니다.
- 스크린샷은 사용자가 시킬 때만 찍습니다. 눈으로 못 본 것은 «눈으로 확인 안 함»이라고 적습니다.

## 코드 검토

- 쓰는 때: 개발 단계에서 테스트 단계로 넘어가기 전, 출시 단계에 들어가기 전.
- ⛔ 먼저 사용자에게 묻고, 승인을 받은 뒤에만 돌립니다. 사용량이 더 든다고 함께 말합니다. 묻는 법은 `data/asking.md` 를 따릅니다.
- 하는 법: 승인을 받으면 `code-review` 스킬을 부릅니다. 그 스킬이 없으면 `code-reviewer` 에이전트에게 맡깁니다.
- 거절하면 다시 묻지 않고 그대로 넘어갑니다. 같은 자리에서 한 번만 묻습니다.

## 중요한 기능 독립 확인

- 쓰는 때: 턴 끝 안내가 «중요한 기능 독립 확인 대기»를 알렸을 때. 결제 · 로그인 · 개인정보 · 서버 권한 기능의 개발 · 수정 세부기능을 완료로 적으면 생깁니다.
- 하는 법:
  1. 안내에 적힌 `independent_check.py 설명 <기능> <세부기능>` 을 돌려 설명 파일을 짓습니다.
  2. Agent 도구로 `feature-verifier` 에이전트를 띄웁니다. 그 설명 파일 경로만 줍니다. 당신의 설명이나 «다 됐다»는 판단을 덧붙이지 않습니다.
  3. 에이전트가 판정을 적습니다. 통과면 완료가 되고, 실패나 사람이면 «확인 필요»로 남습니다.
- 막지 않습니다. 실패면 사용자에게 알리고 하던 일을 이어 갑니다.
- 에이전트를 띄울 수 없는 도구면 사용자에게 «독립 확인을 못 했습니다»라고 알립니다. 판정을 대신 적지 않습니다.
- 사용자가 «이것도 중요해»라고 하면 `ledger.sh 중요기능 <기능>`, «이건 아니야»라고 하면 `ledger.sh 중요기능뺌 <기능>` 으로 적습니다.

## 전용 에이전트

- `code-explorer`: 코드를 넓게 읽어야 답이 나올 때 맡깁니다. 본 대화가 파일 내용으로 차지 않습니다.
- `code-reviewer`: 사용자가 승인한 코드 검토를 맡깁니다.
- `feature-verifier`: 중요한 기능의 독립 확인을 맡깁니다. 설명 파일 경로만 줍니다.
- 에이전트의 판단은 그대로 옮기지 않습니다. 파일을 직접 열어 확인한 뒤 옮깁니다.

## 필요한 순간에 AI 도구 소개

손님이 도구가 있는지 몰라 못 쓰는 일을 줄입니다. 있다는 것을 알리고, 고르는 것은 손님이 합니다.

- 쓰는 때: 앱 아이콘 · 스토어 이미지 · 소개 영상 · 내레이션이 필요한데 손님에게 자료가 없을 때, 앱에 AI 기능을 넣기로 했을 때.
- 하는 법: `brain.sh <지금 단계> 도구/이미지디자인`(또는 `도구/영상음성`, `도구/모델`)로 목록을 받아 그 안내대로 소개합니다. 답은 `data/asking.md` 대로 선택지로 받습니다.
- 같은 일에는 한 번만 소개합니다. 손님이 «이런 안내 그만»이라고 했으면 소개하지 않습니다.
- 가격을 적지 않습니다. 대신 가입하거나 결제하지 않습니다.
