# 야간비행

야간비행은 클로드 코드에 붙는 플러그인입니다.
개발자 없이 혼자 앱을 만드는 사람이 출시까지 가도록 돕습니다.

- AI가 한 대화에서 같은 파일을 여러 번(기본 8번) 고치면, 멈추고 접근을 다시 보라고 AI에게 알립니다.
- 정한 것, 막힌 길, 표준 방식을 기록합니다. 다음 대화에서 AI가 그 기록을 이어 받습니다.
- 지금 어느 단계에 있는지, 무엇이 남았는지를 «조종석» 화면으로 보여 줍니다.
- 진단부터 출시 후까지 아홉 단계마다 할 일을 안내합니다.

야간비행은 대신 결정하지 않습니다. 결정에 필요한 것을 정리해 보여 드립니다.

## 필요한 것

| 무엇 | 비고 |
|---|---|
| 맥(macOS) | 맥에서 시험했습니다. 윈도우와 리눅스는 시험하지 않았습니다. |
| 클로드 코드 | 클로드 유료 요금제(Pro 이상)가 필요합니다. 무료 요금제로는 쓸 수 없습니다. |
| 파이썬 3 | 맥은 개발자 도구를 깔면 들어 있습니다(터미널에서 `xcode-select --install`). 없으면 야간비행이 거의 돌지 않습니다 — 기록 이어받기 · 첫 대화 진단 · 조종석 · 검사 · 라이선스 키 확인이 모두 파이썬을 씁니다(대화를 시작할 때 없다고 알려 드립니다). |

## 설치

1. 클로드 코드를 여십시오(클로드 앱의 Code 탭이나 터미널).
2. 대화창에 아래 글을 **통째로** 복사해 붙여 넣으십시오.

   ```
   야간비행 플러그인을 설치해줘.
   터미널에서 claude plugin marketplace add lovolve/nightflight 를 실행하고,
   이어서 claude plugin install nightflight@lovolve 를 실행해.
   claude 명령이 없으면 Claude 앱 안에 들어 있는 claude 실행 파일을 찾아서 써.
   ```

3. AI가 설치해도 되는지 물으면 「응」이라고 답하십시오. 다른 곳의 코드를 컴퓨터에 들이는 일이라 한 번 묻는 것이 정상입니다.
4. 설치가 끝나면 클로드 코드를 다시 여십시오.

## 처음 쓰기

1. 새 대화를 여십시오. 제품 폴더가 없어도 됩니다.
2. 「야간비행 시작하자」라고 말씀하십시오.
   - 제품 폴더가 아닌 곳(홈 폴더 등)이면 제품 이름을 묻고, 그 이름으로 폴더를 만들어 등록합니다. 클로드 앱에서는 대화를 그 폴더로 옮기고, 터미널에서는 그 폴더로 다시 여는 한 줄을 알려 드립니다.
   - 이미 만들던 제품의 폴더에서 열었다면 그 폴더를 등록합니다.
3. 첫 대화에서 AI가 이 컴퓨터를 점검하고, 몇 가지를 묻습니다.
4. 그 뒤로 대화가 끝날 때마다 기록과 조종석이 저절로 바뀝니다.

## 기록은 어디에 남나

- 기록은 그 제품 폴더 안(`.nightflight/`)에 남습니다. 기록 내용은 야간비행 서버로 보내지 않습니다.
- 조종석 화면을 쓰면, 그 화면에 보이려고 기록의 사본(정한 것 · 막힌 길 · 기능 진척 · 이 컴퓨터의 메모리와 디스크 상태)을 클로드 계정의 비공개 페이지(아티팩트)에 올립니다. 그 페이지는 그 계정만 봅니다.
- 야간비행 서버는 단계별 안내와 이용권 확인에 필요한 값만 받습니다:
  단계 번호 · 받으려는 안내의 갈래 · 이 컴퓨터를 가리키는 번호(설치 때 만든 무작위 번호와, 하드웨어 번호를 한 방향으로 바꾼 값) ·
  제품 번호(앱의 번들 ID — 웹 제품이면 `package.json` 의 이름이나 폴더 이름) · 라이선스 키(넣으실 때) ·
  키를 넣었는지 여부 · 같은 요청이 두 번 세지지 않게 붙이는 무작위 요청 번호.
- 받는 값 전체와 보관 기간은 판매 페이지의 개인정보 처리방침에 있습니다.

## 가격

| | 무료 | 라이트 | 플러스 |
|---|---|---|---|
| 쓸 수 있는 제품 | 컴퓨터 한 대에 1개 | 동시에 3개 | 동시에 15개 |
| 가격 | 0 | 월 10달러 · 연 100달러 | 월 30달러 · 연 300달러 |

- 검사, 경고, 조종석, 기록은 모든 요금제에 들어 있습니다.
- 클로드 구독료는 따로 듭니다. Anthropic에 직접 내십니다.
- 자세한 내용은 판매 페이지의 가격 · 환불 · 약관을 보십시오.

## 이 폴더의 구성(개발자용)

| 폴더 | 무엇 |
|---|---|
| `hooks/` | 훅 일곱을 등록합니다 — 대화 시작(기록 이어 받기) · 말을 보낼 때 셋(낱말 사전 · 라이선스 키 붙여 넣기 — 키가 든 말은 AI에게 보내지 않고 막습니다 · 정리하라는 말 듣기) · 파일을 고친 뒤(같은 파일 반복 알림) · 턴 끝 둘(검사 · 조종석). 이유는 `hooks/왜.md`에 있습니다. |
| `bin/` | 훅이 부르는 스크립트와 기록 도구(`ledger.sh`)입니다. |
| `tools/` | 검사 도구입니다. 대화가 끝날 때마다 돕니다. |
| `skills/` | 아홉 단계 스킬, 라이선스 키 스킬, 이미 만들던 제품의 기록을 채우는 가져오기 스킬입니다. |
| `board/` | 조종석 화면입니다. `board/README.md`에 어느 파일이 생성물인지 적었습니다. |
| `data/` | 검사와 화면이 읽는 표입니다(용어집 · 낱말 사전 · 출시 절차 등). |
| `AGENTS.md` | 이 저장소를 고치는 AI가 따르는 규칙입니다. 플러그인으로 깔리면 어느 도구도 이 파일을 읽지 않습니다. |
| `RULE-0.md` | 사용자에게 보이는 글의 규칙입니다(사용자는 비개발자다). |
